# Beta playback access

Official Jellyfin beta builds require the shared MisterZine supporter code to
start playback. Signing in, browsing your library, and configuring the app are
available without it. The code is separate from Jellyfin Quick Connect and your
Jellyfin password.

Choose Play or Resume to enter the six-digit code, or open **Options > Beta
access**. Successful entry is saved on the SD card and survives updates and
rollback. Keep that saved access when moving an installation to another card.
An incorrect code leaves playback locked and can be tried again.

The code unlocks its beta batch offline. It does not expire or check membership
over the network. Keep access for older batches if you want to run those
releases. Obtain the current shared code through the MisterZine supporter
channel; never include it in bug reports.

Stable releases do not require a beta code. Development builds from source are
also ungated. The beta gate is a convenience for distributing early builds,
not a security boundary or a DRM system.
