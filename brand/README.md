# Brand assets

Source artwork for MisterZine apps: the wordmark's SVG sources
(`tools/prep_wordmark.py` derives the knockout and layered files from the source
trace) and PNG exports, retained for reproducibility. Nothing here is loaded at
run time; the app's header mark is `app/internal/ui/assets/MZjellyfin.png`.
The renderer corrects aspect ratio for CRT pixels.

These assets are original application material; third-party names retain their ownership.
